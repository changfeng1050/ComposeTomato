### 踩坑记录

- KMP 桌面目标编译任务是 `compileKotlinDesktop`（`compileKotlin` 会报歧义）
- Compose resources 的字符串/图标是扩展属性，需逐个 import（如 `com.changfeng.tomato.resources.tomato`）
- Kotlin 尾随 lambda 会绑到最后一个参数（哪怕是 Modifier），带函数参数+Modifier 默认参数的 Composable 调用要用命名参数
- 属性 setter 与同名 fun 会 JVM 签名冲突（noteLink/setNoteLink → 函数改名 linkNote）
- Kotlin stdlib 的 String.replaceFirst (regex) 没有 lambda 重载，用 matchResult.range 手动截取

## 便笺改版：单 TextField + Alt+Enter（2026-09-29）

- 用户要求：所有便签放回单个多行 TextField，一行一个事项；Alt+Enter 将当前行标记完成（划线）
- 实现：BasicTextField + TextFieldValue（拿光标 selection）；Alt+Enter 在 onPreviewKeyEvent 拦截，toggleLineAtCursor 切换行首
  `[x]` 标记
- 划线渲染：VisualTransformation 对 `[x]` 行加 SpanStyle (LineThrough+灰)，编辑能力不受影响
- NotesRepo 回到单条 text 格式；旧多条 notes.json 自动合并迁移（按 createdAt 排序 joinToString）
- SelectNoteScreen 改为列出便笺各行（事项），关联快照=行文本；NoteLink.noteId 变可空
- CONTEXT.md 便笺/事项/清单行定义同步更新；删除 ChecklistText.kt（checkbox 卡片方案废弃）
