# 数据文件保留在程序工作目录

番茄钟的持久化文件（`settings.json`、`notes.json`、未来的番茄记录文件）继续存放在程序运行目录，而不是迁移到
`%APPDATA%/Tomato/` 等用户配置目录。

这是一个刻意的取舍：本项目定位为 **个人工具**（ADR 前提，见 2026-09 设计讨论），通常以绿色免安装方式放在用户自己的目录（如
`F:\mywork`）下运行，工作目录用户可写，数据随程序目录一起备份和搬运更直接。迁移到 APPDATA 反而会让数据分散、不便于随目录整体拷贝。

代价与已知边界：若未来正式发布安装版、或被放到无写权限的目录（如 Program
Files）下运行，写入会失败。届时再引入"数据目录可配置 + 旧数据自动迁移"方案，并推翻本决策。
